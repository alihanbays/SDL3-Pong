# SDL3 Pong

A Pong clone built from scratch with C++ and SDL3.

### Dependencies
* SDL3
* SDL3_image
* SDL3_ttf
* SDL3_mixer

### Controls
* **Player 1**: Use **W** and **S** to move.
* **Player 2**: Use the **Up** and **Down** arrows to move.

### How to build

The project uses CMake.

```bash
cmake -B build
cmake --build build
./build/Pong
```
